# Clawdbot Canvas - Design Direction

## Philosophy
Minimalist, Apple-inspired design. Every element should feel intentional, with generous whitespace and subtle interactions.

## UI Framework
- **Shadcn/UI** - Component library
- **Vercel AI Elements** - AI-specific components
- **Tailwind CSS** - Styling

## Visual Principles

### Typography
- Clean sans-serif (SF Pro / Inter / system fonts)
- Limited font weights (regular, medium, semibold)
- Generous line height

### Colors
- Neutral base (whites, grays, blacks)
- Subtle accent color for interactive elements
- Dark mode support

### Spacing
- Consistent spacing scale (4px base)
- Generous padding and margins
- Breathing room between elements

### Motion
- Subtle, purposeful animations
- 200-300ms transitions
- No gratuitous movement

### Components
- Rounded corners (soft, not bubble-like)
- Subtle shadows for elevation
- Clear visual hierarchy

## Widget Design
Widgets should be:
- Self-contained cards with clear boundaries
- Glanceable - information visible at a glance
- Minimal chrome - content over decoration
- Responsive - work at various sizes

## Reference
Think: Apple's recent macOS/iOS design, Linear, Raycast, Arc browser
